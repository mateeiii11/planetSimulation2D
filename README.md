# 2D Planet Simulation

2D Planet Simulation, using Newton's Universal Law of Gravitation, written in C++, using OpenGL.

## Overview

This project was made in 2025, and this README is being written in 2026. Back then I did not know what commits and github are for, I just wanted to
have my project somewhere.

## Running the project

* Clone the repository
* Navigate to `/x64/Release/`
* Launch the `.exe` file
